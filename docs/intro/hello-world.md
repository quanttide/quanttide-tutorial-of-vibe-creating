# AI视频叙事提示词撰写教程

面向即梦 / Sora / Vidu 等文生视频工具

阅读顺序：先看成品 → 再懂原理 → 最后自己写


开篇：先看一个完整案例

下面这段提示词，就是我们本教程要拆解的样本。它生成的效果如图：

提示词原文：

竖屏 9:16，电影质感。

咖啡店暖黄灯光，窗外下着小雨。

陆知微拖着粉色行李箱推开玻璃门进店，环视满座，目光与坐在靠窗卡座的林远亭撞上，两人同时愣住。她拖着行李箱走到桌前，低声问：”对面有人坐吗？“他点头。他从背包掏出一条未拆封毛巾，撕到一半停住，随即伸手轻轻擦去她发梢的水珠，动作很轻，她呆住不敢动。他回神，把毛巾递给她，两人指尖相触，各自一颤。她低头接过，轻声说：”谢谢亭神。“

镜头中近景，缓慢推近，正反打，浅景深。

成品图：

先记住这个画面的三个细节：撕到一半的毛巾、极轻的擦水珠动作、将触未触的指尖。接下来我们看这段文字是怎么”长出“这个画面的。


——

第一章 结构总览：四层模型

把上面那段提示词拆开，会发现它由四个层次按顺序叠成，缺一不可：

层级	名称	对应原文	作用
L1	技术参数	竖屏 9:16，电影质感	定规格与风格
L2	场景氛围	咖啡店暖黄灯光，窗外小雨	搭舞台、定情绪
L3	叙事动作	推门→愣住→擦水珠→指尖相触	剧情骨架
L4	镜头语言	中近景，推近，正反打，浅景深	导演调度

口诀：框架 → 舞台 → 剧情 → 镜头。下面逐层回到原文，看你写的每个字落在了哪里。


——

第二章 逐层还原

2.1 L1 技术参数（1 句）

竖屏 9:16，电影质感。

• 竖屏 9:16 定画幅，适配手机端竖屏观看

• 电影质感 定风格，暗示浅景深、平滑影调、胶片感

• 永远放在最前，越短越好

2.2 L2 场景氛围（1 句）

咖啡店暖黄灯光，窗外下着小雨。

• 暖黄灯光 定色温与情绪基调（温暖、暧昧、安全）

• 窗外小雨 加动态环境元素，让背景”活“起来，同时强化雨夜咖啡馆的浪漫意象

2.3 L3 叙事动作（核心，占比最大）

这是全篇骨架，原文几乎一半篇幅都在这一层。它写成了一条连续动作链：

阶段	原文动作	作用
入场	拖粉色行李箱推门、环视满座	交代人物与处境
相遇	目光撞上、同时愣住	制造冲突点
试探	”对面有人坐吗？“→点头	对白推进关系
高光	撕到一半停住→轻擦水珠→呆住	情绪峰值
落点	递毛巾→指尖相触→各自一颤	留白收尾

两个关键写法：

① 写动作链，不写状态。

❌ ”两人尴尬地相遇“

✅ ”推门 → 环视 → 目光相撞 → 同时愣住“

② 用微动作锚定情绪。

模型对”深情“”害羞“这类抽象词无感，但对”撕到一半停住“”动作很轻“”呆住不敢动“”指尖相触各自一颤“极其敏感。抽象情绪要翻译成具体身体动作——成品图里那个将触未触的指尖，正是”各自一颤“这四个字撑起来的。

另外，对白用引号嵌入，可顺带交代关系：”谢谢亭神“ 中”亭神“是昵称/尊称，暗示女对男的好感。

2.4 L4 镜头语言（1 句收尾）

镜头中近景，缓慢推近，正反打，浅景深。

• 中近景：景别，框定人物主体

• 缓慢推近：运镜，制造情绪递进

• 正反打：对话场剪辑法，两人交替入镜

• 浅景深：虚化背景，突出人物——成品图里咖啡店与雨窗的柔焦虚化，就来自这四个字

这一层是”导演指令“，把前面的剧情翻译成具体拍摄方案。

第三章 空白模板（套用即写）

理解了上面四层，就可以把案例抽象成模板，替换 【】 槽位即可复用：

【画幅】，【质感风格】。

【场景地点】【光线色温】，【环境动态元素】。

【角色A】【入场动作】，【环视/状态】。
【目光交汇点】撞上【角色B】，两人【同步反应】。
【A移动到B的动作】，【低声对白/试探】。
【B的微动作链：停顿→转折→关键动作】，【动作程度限定】。
【A的反应】，【B的收束动作】，【细节触点】，【情绪落点】。

镜头【景别】，【运镜方式】，【剪辑手法】，【光学效果】。

第四章 自己写一个（对照练习）

下面是套用模板生成的新案例，验证四层是否成立：

成品提示词：

竖屏 9:16，电影质感。

深夜便利店冷白灯光，玻璃门外飘着雪。

苏晚摘下耳机走进店门，抖落肩上的雪，目光扫过空荡的货架。视线与站在热食柜前的江屿撞上，两人同时顿住。她走到他身侧，低声问：”你也加班到现在？“他”嗯“了一声，把刚拿到的关东煮往她那边推了推，推到一半又收回来，随即拆开一双一次性筷子递过去，动作很慢，她没接，任由筷子搁在两人之间的柜台。他回神，收回手，指节轻轻叩了下台面，两人各自别开脸。

镜头近景，缓慢横移，正反打，浅景深。

槽位对照： L1 竖屏+电影质感 / L2 便利店冷白灯+飘雪 / L3 入场→相遇→”推一半又收回“的高光→”别开脸“的留白 / L4 近景+横移+正反打+浅景深。注意情绪全由”推一半收回“”没接“”别开脸“承载，没有一个抽象形容词。

第五章 动笔前检查清单

• [ ] 四层顺序是否为 L1→L2→L3→L4？

• [ ] L3 是否写成连续动作链，而非状态描述？

• [ ] 是否至少设计了 2 处”微动作/停顿“作为情绪锚点？

• [ ] 抽象情绪词是否已翻译成具体身体动作？

• [ ] 对白是否用引号包裹，并交代了人物关系？

• [ ] L4 是否包含景别、运镜、光学三要素？


——

第六章 常见错误速查

错误类型	反例	修正方向
形容词堆砌	”两人深情对视，气氛暧昧“	换成具体微动作
顺序混乱	先写镜头再写场景	严格按 L1→L4
动作跳跃	”相遇后她抱住了他“	补全中间试探链
缺镜头指令	结尾无景别/运镜	补一句 L4
环境死寂	只有场景没有动态	加雨/雪/风等活元素
